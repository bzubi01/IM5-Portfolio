# Portfolio – Grundgerüst

Reines HTML, CSS und JavaScript, ohne Framework oder Build-Tool.

## Ordnerstruktur

- index.html: Navigation und Sections für Start, Projekte, Über mich und Kontakt.
- css/style.css: vorbereitet für die spätere Gestaltung.
- js/main.js: Einstiegspunkt für das spätere JavaScript.
- assets/images/: Bilder und Projektbilder.
- assets/icons/: Icons.
- assets/fonts/: lokale Schriftdateien, falls benötigt.

Die .gitkeep-Dateien halten die noch leeren Asset-Ordner in Git fest.

## Öffnen

Zum Ansehen index.html im Browser öffnen. Es sind keine Abhängigkeiten nötig.
Für die spätere Datenanbindung verwenden wir einen lokalen Webserver.

## Bewusst noch offen

Keine Farben, Schriften, Layouts, Projektinhalte oder Animationen festgelegt.
Die Navbar hat noch keine Höhenvorgabe. Das Canvas ist leer und verwendet
vorerst seine Browser-Standardgrösse. Die WordPress REST API wird später angebunden.
